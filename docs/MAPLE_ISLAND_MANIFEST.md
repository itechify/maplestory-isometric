# Maple Island manifest (built world)

Generated by `scripts/export_manifest.py` from `src/misostory/layout.py`, `docs/build_report.json` and the MeowDB MS Classic maps (`game/data/canonical/maps`, found through `game/data/misostory/map_id_crosswalk.json`). Positions are meters in Blender world space. The world-map frame is the same space rotated so north is up, which is how the classic in-game world map is drawn.

NPCs and monsters (MeowDB) are MeowDB's lists: NPC names and, per species, the number of spawn points. The built columns are what the Blender world holds: NPC proxies, and the representative monster proxies (a visual placeholder per spawn area, not the spawn count; the runtime spawns MeowDB's monsters in the authored spawn regions).
