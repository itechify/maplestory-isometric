# Nunito (SIL Open Font License 1.1)

- File: `Nunito-Variable.ttf`, the unmodified variable font `ofl/nunito/Nunito[wght].ttf` from the official
  google/fonts repository (https://github.com/google/fonts/tree/main/ofl/nunito), renamed only because `[` and `]`
  are awkward in `res://` paths. Weight axis 200-1000.
- License: `OFL.txt` beside it (copied from the same directory). Copyright 2014 The Nunito Project Authors
  (https://github.com/googlefonts/nunito).
- Used by `res://scripts/ui/theme/miso_theme.gd` (MisoTheme) for every MisoStory UI text. Weights come from
  `FontVariation` coordinates on the `wght` axis; no glyph is modified.
