# MisoStory

Classic Maple Island rebuilt as one isometric 3D island and a playable game on it. Its content follows what the
project's sources publish about the classic game; this glossary names the ways a piece of work or a value can stand
relative to those sources and to the project's plans.

## Language

**Canonical**:
Published by one of the project's two sources, MeowDB MS Classic or Henesys.gg, and traceable to the page that says it.
_Avoid_: Official, original, GMS

**Source-data gap**:
A canonical value that none of the project's sources publishes. It is never guessed, and it ends only when a source
publishes the value.
_Avoid_: Unknown, placeholder, TBD

**Adaptation**:
A MisoStory rule that stands in where the canonical value is missing or does not translate to isometric 3D. It is
marked unverified, and changing one is the owner's decision.
_Avoid_: Placeholder, guess, house rule

**Brief**:
The document that set one iteration's goal, scope and definition of done. Iterations One to Three each had one; work
since then is planned as tickets.
_Avoid_: Spec, plan, roadmap

**Out of scope**:
Work that a Brief excludes. It may come back in a later plan, unlike work that was considered and rejected (wontfix).
_Avoid_: Wontfix, deferred

**Deferred**:
Work accepted as worth doing but not yet scheduled. Every deferred item has a ticket.
_Avoid_: Out of scope, postponed, backlog item
